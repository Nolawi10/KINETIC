# KINETIC - Affordable Multimodal Sports-Intelligence System

**KINETIC** is an AI/ML research platform for low-cost sports training, using simulated and eventually real sensor measurements, computer vision, intelligent event recognition, and adaptive training feedback.

## Core Research Question

Does combining low-cost physical sensors with computer vision improve combat-movement event recognition compared with either modality alone, and can the resulting measurements support safe, personalized training drills?

## System Overview

KINETIC combines:
- **Piezoelectric impact sensors** on an instrumented training mannequin
- **IMU** (MPU6050) for motion sensing
- **Smart mat** for footwork tracking
- **Camera** with pose estimation (YOLO Pose or MediaPipe)
- **Sensor-vision fusion** for robust event recognition
- **Adaptive coaching engine** for personalized drill selection

## Hardware Components

- Instrumented striking mannequin with piezoelectric sensors
- MPU6050 inertial measurement unit
- Smart mat with zone detection
- Camera (webcam or similar)
- ESP8266 microcontrollers
- Raspberry Pi 5 for intelligence pipeline

## Quick Start

### ML Pipeline
```bash
# Generate synthetic dataset (small test)
python scripts/generate_synthetic_data.py --config configs/simulation.yaml --size small

# Extract features
python scripts/extract_features.py

# Create train/validation/test splits
python scripts/create_splits.py

# Train baseline models
python scripts/train_models.py --baseline

# Evaluate models
python scripts/evaluate_models.py

# Generate figures and report
python scripts/generate_all_figures.py
python scripts/generate_report.py
```

### Full Stack (Frontend + Backend)

#### Backend Setup
```bash
cd backend
python -m venv venv
venv\Scripts\activate  # On Windows
pip install -r requirements.txt
python app.py
```

The backend will run on `http://localhost:5000`.

#### Frontend Setup
```bash
cd Frontend
npm install
npm run dev
```

The frontend will run on `http://localhost:8080`

#### One-Command Full Stack
```bash
cd backend
venv\Scripts\activate   # Windows
python app.py
```

`app.py` starts **both** the Flask API (`:5000`) and the Vite frontend (`:8080`),
waits until both respond, then opens the app in your browser. `CTRL+C` stops both.

#### API Integration
The frontend is configured to connect to the backend via the `VITE_API_URL` environment variable in `Frontend/.env`. Make sure the backend is running before starting the frontend.

## Important Notes

### Synthetic Data
All current data is **synthetic** and generated by configurable simulators. This demonstrates software functionality but does not establish real-world accuracy, athlete safety, or injury prevention capabilities.

### Safety Disclaimer
- Sensor amplitudes are relative indicators until physically calibrated
- 2D pose measurements are 2D observations, not reliable 3D biomechanics
- Do not diagnose injuries or prescribe medical treatment
- This system is for training feedback, not medical diagnosis

### Evaluation Limitations
- Group splitting within synthetic datasets evaluates generalization across simulated profiles, not real people
- Results apply to the simulator's assumptions and parameter ranges
- Real-hardware validation is required before deployment claims
