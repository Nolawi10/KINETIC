# Cybernetic Coach

Create the initial component for the "KINETIC AI MMA Trainer" web interface. We are building a high-end, cyberpunk-tactical dashboard optimized for a touch screen.

For starters, build the header navigation bar matching this exact specification:

1. Aesthetic & Colors: Use a sleek, floating pill-shaped capsule navigation bar centered at the top. The background should be a frosted liquid glass style (semi-transparent dark charcoal/gray with `backdrop-filter: blur`, a subtle soft border, and smooth depth).

2. Navigation Items: Include tabs for "Dashboard", "Training Modes", "Live Session", "Analytics", and "Settings".

3. Accent Lighting: Incorporate subtle neon highlights—use a vibrant electric blue (cyan) active indicator state or glow for selected/hover states, with occasional sleek red neon warning accents for system status elements.

4. Layout & Behavior: The bar should be fixed at the top, centered horizontally, with a clean margin, fully responsive and ready to handle active state tab switching for the application.
